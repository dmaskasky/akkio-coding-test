# Color Swatches

A small React app that shows a grid of **HSL color swatches** using [The Color API](https://www.thecolorapi.com/). Adjust saturation and lightness to see distinct named colors; click a swatch to view its detail page.

- **Stack:** React, TypeScript, Vite, TanStack Router, TanStack Query, Jotai
- **Run:** `pnpm install && pnpm dev`
- **Test:** `pnpm test`
